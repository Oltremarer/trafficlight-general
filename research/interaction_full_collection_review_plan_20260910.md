## 6. 指标与分析

原始每秒物理量全部保留，先在原始单位相减形成效应，之后才可归一化。不同单位不直接拼成一个好看的总分。

| 指标 | 5秒处理及含义 |
|---|---|
| 分车道三段车辆数N、停车数Q | 窗口末端；Q为速度<0.1m/s，不是米制队列长度 |
| 道路停车等待 | 每秒Q积分，保留逐车道，单位车·秒 |
| 路口内部停车等待 | laneLink停车数积分，按路口，不与道路重计 |
| 入口等待 | boundary_pending积分，防止靠堵在网外获利 |
| 速度损失 | 道路/路口分别积分，不冒充平均旅行时间 |
| movement放行/接收 | 分别累计，保留通过laneLink的时间差 |
| 边界生成/入网/出网 | 事件口径分别保留 |
| 内部完成分车道/内部完成/总完成 | 三个新增字段按窗口累计 |
| 尾车位置速度/接纳不可用 | 末端状态与不可用秒数；后者仅风险代理，不等于真实spillback |
| unresolved_events | 累计保留，不默认归入正常完成；异常保留定位证据 |

分析同根基准F0、单项Fi、双项Fij和多项Fjoint：

- 单项效应=Fi−F0。
- 双项交互=Fij−Fi−Fj+F0。
- 低阶重构=F0+对应单项效应+对应双项交互。
- 联合残差=Fjoint−低阶重构；8/16路口残差是全部三阶及以上合计，不是纯三阶。
- 四路口全256面板可用全部子集计算纯三/四阶；面板没采完就不冒充完整面板结果。

从同一180秒数据派生30/60/120/180秒及36个5秒窗口，不重新仿真多个horizon。先逐车道/段、路口、入口计算误差，再取绝对值聚合，避免全网正负抵消。

报告每根、flow、策略、时刻、动作规模的结果；再按根/flow汇总，不能让快场景的大量branch主导平均。只有3个同源flow，不把数万branch当独立样本，不声称可靠泛化置信区间。相对误差以动作效应大小为基准，效应接近0时单列绝对误差，不用庞大的背景等待稀释误差。

完整根看120对交互强度集中曲线；缺失pair是未知，不是0。真值top-k筛边只给oracle上限，不是可部署模型。保留远距离和共享下游关系，不用邻接提前删pair，也不硬编码所有影响在整段L/v前严格为0，尤其注意反向接纳影响。

固定候选目标J=道路停车等待+路口内部停车等待+入口等待，均为车·秒；完成量、速度损失、接纳风险单列。比较同一已采且引用齐全候选集的排序/regret，未完成根清楚限定候选范围，不冒充全网全联合最优。

该分析使用CityFlow真值效应因子，不是训练完的World Model。高阶误差大或只在轻载可加也是有效结果，不设90%通过门槛。
