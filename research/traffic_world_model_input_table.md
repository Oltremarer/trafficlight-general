# 交通 World Model 输入表

这套输入面向结构化 CityFlow 轨迹。策略名称不进入模型；模型只看到历史状态、实际执行动作和静态路网。训练样本使用最近 3 个决策周期，预测未来 1–5 个周期。

| 层级 | 输入 | 处理方式 | 是否进入首版模型 | 作用 |
|---|---|---|---|---|
| 每个 movement | 进入车辆数、进入排队数、下游车辆数、下游排队数 | 原值做有符号 `log1p` 后按训练集标准化 | 是 | 主要交通存量 |
| 每个 movement | 进入平均速度、下游平均速度、进入速度标准差、停车比例 | 由 CityFlow 车辆速度和车道车辆列表聚合 | 是 | 区分“车多但流动”和“车多且堵死” |
| 每个 movement | 平均位置进度、位置进度标准差 | 车辆在当前车道的距离除以车道长度 | 是 | 描述车群离停止线还有多远 |
| 每个 movement | 平均车头间距 | 按车道位置排序后计算相邻车辆距离 | 是 | 描述交通密度和车群结构 |
| 每个 movement | 停止线前 50 米、100 米车辆数 | 用车道长度减车辆当前位置聚合 | 是 | 描述即将到达路口的车辆 |
| 每个 movement | 最近到达率、最近离开率 | 相邻决策周期车辆集合变化除以时间间隔 | 是 | 描述短期流入、流出速度 |
| 每个 movement | 上游占有率、下游占有率 | 车辆数除以估计车道容量 | 是 | 识别饱和与下游溢出 |
| 每个 movement | 车辆 pressure、排队 pressure | 上游量减下游量 | 是 | 保留 MaxPressure 直接使用的信号 |
| 每个路口 | 当前相位、信号阶段、相位持续时间 | 相位/阶段嵌入，加连续持续时间 | 是 | 还原当前信号状态 |
| 每个路口 | 候选动作/实际动作 | 离散相位与邻居相位编码成 6 维动作向量 | 是 | 让模型学习“换不同灯会发生什么” |
| 静态 movement | 进/出车道数、平均长度、估计容量、限速 | 从 roadnet 解析，一条车道容量暂按长度/7.5 米估计 | 是 | 给不同道路尺度统一语义 |
| 静态 movement | 左转/直行/右转、边界入口/出口 | one-hot 或二值标记 | 是 | 区分 movement 类型与边界流 |
| 静态路口 | `phase_movement_mask` | 当前动作对应的放行 movement 掩码 | 是 | 明确每个动作实际放行哪些车流 |
| 静态路网 | 邻居索引和有向连接 | 图邻居聚合 | 是 | 建模上游放行对本站流入的影响 |
| 全局 | 当前仿真时间 | `log1p(time)` 加周期正余弦 | 是 | 描述一个周期内的时间位置 |
| 全局 | 需求条件 | flow 数、估计车辆总数、平均发车间隔、首末发车时间 | 是 | 区分不同需求强度和时间范围 |
| 历史 | 最近 3 个完整决策周期 | 保存为 `[历史, 路口, movement, 特征]` 窗口 | 是 | 让模型辨别上升、下降和传播趋势 |
| 车辆级原始记录 | 每辆车 ID、速度、位置、所在车道 | 采集时用于上述聚合；不直接形成固定长度输入 | 否 | 原始数量可变，直接输入会随交通量爆炸并依赖不稳定车辆 ID |
| 可选后续扩展 | 单车路线、车型、精确前车 ID | 需要额外可变集合编码器和更高采集开销 | 否 | 首轮先验证聚合微观量是否已经足够 |

## 三方对照

| 对照项 | 模型实际做什么 |
|---|---|
| CityFlow | 产生真实下一时刻，作为唯一真值，不参与学习预测 |
| 不使用持久内部状态 | 每一步从最近 3 个观测重新编码，直接预测下一组交通量；多步时把预测的观测再喂回模型 |
| 使用内部状态 | 先把最近 3 个观测压成潜状态，再按动作在潜状态里连续演化 1–5 步，最后解码为可比较的交通量 |

两种学习模型使用同一批训练轨迹、同一输入、同一训练/验证划分和同一 CityFlow 真值。区别只在于是否保留并滚动一个学习到的内部状态。
